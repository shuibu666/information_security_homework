# Course Project Layout

To make this repository easier to submit for coursework, all custom improvement files are grouped under:

```text
course_project/
```

Official baseline files remain in the repository root, while your coursework additions are separated into:

- `course_project/processors/`
- `course_project/scripts/`
- `course_project/data/`
- `course_project/outputs/`
- `course_project/docs/`

Detailed instructions are available in:

```text
course_project/docs/README_SUBMISSION.md
```
